# 💰 Expense Tracker & AI Intelligence Dashboard

A modern, full-stack financial tracking application designed to help users monitor their daily expenses, track income, manage budgets, and gain deep AI-driven financial insights.

---

## ✨ Features

### 📊 Financial Dashboard & Tracking
* **Expense & Income Tracking:** Easily log, categorize, and track daily cash flows.
* **Budgeting:** Set category-wise budget targets to stay on top of monthly spending limits.
* **Analytics & Visualizations:** Interactive charts and breakdowns of spending behavior over time.

### 🧠 AI Financial Insights
* **Financial Health Score (A+ Rating System):** Automatically calculates a total health score out of 100 based on key factors:
  * **Savings Rate:** Benchmark evaluation (target $\ge$ 20%).
  * **Expense Ratio:** Spending relative to total income.
  * **Budget Adherence:** Tracking against set budget limits.
  * **Recurring Commitments & Financial Consistency:** Stability and variance analysis.
* **Investment Readiness Assessment:** Analyzes liquid safety buffers (in months) and net surplus to determine investment readiness.
* **Predictive Expense Forecasting:** 
  * Tracks month-to-date spending pace (e.g., day elapsed vs. spent ratio).
  * Category-wise end-of-month projections (Food, Housing, Other).
* **Anomaly Detector:** Highlights unusual spending patterns and potential transaction outliers.
* **Behavioral Trend Analysis:** Identifies concentration spikes (e.g., housing cost dominance) and weekend spending trends.

---

## 🛠️ Tech Stack

* **Frontend:** React / Next.js, TypeScript, Tailwind CSS
* **Icons & UI:** Lucide React, Framer Motion (Animations)
* **Backend / Database:** Node.js / Express (or Next.js API Routes), PostgreSQL / MongoDB (or Prisma ORM)
* **AI / Intelligence Engine:** Custom financial analysis algorithms & predictive statistical models
